# **App Name**: Battleship - Web Version

## Core Features:

- Ship Placement: Interactive ship placement interface allowing players to drag and drop their ships onto their game board before starting the game.
- Turn Management: Turn-based gameplay enabling players to take turns selecting coordinates on the opponent's board to target their ships.
- Hit/Miss Feedback: Visual feedback system providing immediate updates on the game board to show hits, misses, and sunk ships for both players.
- Current Player Display: Display messages, for example, whose turn is it, if the player has sunk an enemy ship or won the game.
- Real-time Sync: WebSockets integration for real-time communication between players during gameplay.

## Style Guidelines:

- Primary color: Navy blue (#2E5CB8), evoking the nautical theme of naval warfare.
- Background color: Light blue (#D1E4F7), to provide a calm and clean backdrop reminiscent of a serene sea.
- Accent color: Electric blue (#7DF9FF), highlights interaction points such as buttons.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text, offering a modern yet legible design.
- Use a set of simple and modern icons to represent ships, hits, and misses on the board.
- Boards of players are displayed on each side of the screen.
- Smooth transitions and animations during ship placement and attack sequences to enhance user engagement.
